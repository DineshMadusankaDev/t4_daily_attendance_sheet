# T4 Night Shift Attendance\n\nMobile-friendly attendance tracker for the fixed T4 night-shift roster (18:30–06:30).\n\n## Features\n- Fixed 26 Labour IDs\n- Present / Absent / Leave status selection\n- Save and edit attendance by shift start date\n- WhatsApp share and copy-ready daily summary\n- Weekly/monthly/custom date-range reports\n- Day-by-day print layout (use Save as PDF in the print dialog)\n- JSON backup and restore\n- Offline-capable installable PWA\n\n## Deploy with GitHub Pages\n1. Open repository Settings → Pages.\n2. Under Build and deployment, choose Deploy from a branch.\n3. Select `main` and `/ (root)`, then Save.\n4. Open the Pages URL on the phone. Use the browser menu → Add to Home screen / Install.\n\n## Important data note\nAttendance records are stored in the browser's local storage on the phone. They are not automatically synced between devices. Export a JSON backup regularly and keep it somewhere safe. Clearing browser/app data can erase records.\n
